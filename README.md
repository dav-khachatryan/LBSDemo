# Supplier evaluation training exercise

Fictional leadership workshop on 20 November 2026, initially for 80 attendees, with a EUR 6,000 total-payable catering budget.

## Deliverables

- [Cost comparison workbook](deliverables/Catering_cost_comparison.xlsx): formulas, compulsory fees, minimum billing, capacity and availability checks, sources and assumptions.
- [One-page recommendation](deliverables/Catering_recommendation.docx): select Supplier B at EUR 4,320 for 80 attendees, leaving EUR 1,680 budget headroom. B has a hard limit of 90 attendees.
- [Reusable supplier-evaluation skill](skills/evaluate-suppliers/SKILL.md): general workflow for comparable costing and hard-constraint evaluation.

Supplier A totals EUR 4,750.80 including its compulsory service charge. Supplier C totals EUR 4,660 based on its 90-person minimum, with event-date availability unconfirmed. All quoted amounts include taxes.

The skill is a standalone instruction package. To use it with a compatible agent, place the `evaluate-suppliers` folder in the agent's configured skills directory. It delegates file creation to the host's available spreadsheet and document capabilities; those platform skills are not bundled here.

No supplier contact or bookings were made. All suppliers and proposals in this exercise are fictional.
